## Introduction  
This document outlines the structure and expectations for the Computer Networks Lab project. The aim of this lab is to provide hands-on experience with various networking concepts and technologies.

## Objectives  
- Understand basic network protocols (TCP/IP, UDP, etc.)  
- Configure network devices (routers, switches)  
- Analyze network traffic using tools like Wireshark  
- Develop skills in network troubleshooting

## Laboratory Setup  
- Hardware Requirements:  
  - PC or laptop with Windows/Linux  
  - Network devices (routers, switches)  

- Software Requirements:  
  - Packet Tracer or GNS3  
  - Wireshark

## Experiments  
1. **Setting up a Local Area Network (LAN)**  
   - Description of the steps involved in configuring a local network.
  
2. **Implementing Routing Protocols**  
   - Explaining the configuration and testing of different routing protocols.
  
3. **Network Traffic Analysis**  
   - Using Wireshark to capture and analyse packets.

## Results and Discussion  
In this section, you will describe the observations from each experiment, what worked, what didn’t, and your understanding of network behaviors based on the experiments.
